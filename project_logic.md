# 📚 ЛОГІКА ТА АРХІТЕКТУРА ПРОЕКТУ ЛІЦЕЮ №8 (project_logic.md)

Цей документ містить повний технічний опис структури додатку, логіки взаємодії модулів та інтеграції штучного інтелекту. Призначений для ознайомлення АІ-агентів з архітектурою проекту перед впровадженням змін.

## 🗺️ 1. ЗАГАЛЬНА АРХІТЕКТУРА
Проект є статичним односторінковим додатком (SPA), побудованим на чистих HTML, CSS та JavaScript. Додаток не використовує серверних фреймворків Node.js у рантаймі і працює безпосередньо в браузері користувача, взаємодіючи із зовнішніми хмарними сервісами.

### Основні зовнішні інтеграції та бібліотеки:
1. **Firebase (Auth, Firestore)** — автентифікація користувачів (зокрема анонімний вхід) та збереження даних (тести, творчі роботи, результати).
2. **OpenRouter API** — доступ до мовної моделі ШІ (Gemini/Mistral) за допомогою каруселі з 10 API-ключів.
3. **Pollinations.ai** — генерація зображень за текстовим описом.
4. **ElevenLabs API & Google TTS** — синтез мовлення (озвучка відповідей ШІ).
5. **MathJax** — рендеринг математичних формул LaTeX.
6. **Tesseract.js** — оптичне розпізнавання тексту (OCR) із завантажених зображень.
7. **PptxGenJS & JSZip** — генерація та експорт слайдів у формат презентацій `.pptx`.
8. **Marked.js** — парсинг розмітки Markdown у повідомленнях чату.

## ⚙️ 2. КОНФІГУРАЦІЯ (`.env`)
Файл [.env](file:///d:/Projects/ліцей_8/.env) реєструє глобальні об'єкти налаштувань у вікні браузера:

* `window.APP_CONFIG` містить:
  * `GEMINI_API_KEYS` — масив з 10 ключів OpenRouter для розподілу навантаження.
  * `POLLINATIONS_API_KEY` — ключ для роботи з Pollinations.
  * `GEMINI_MODEL` — поточна модель ШІ за замовчуванням (наприклад, `mistralai/mistral-7b-instruct:free`).
  * `ELEVENLABS_API_KEY` — ключ для озвучення тексту.
  * `GOOGLE_SCRIPT_URL` — Google Apps Script для надсилання кодів верифікації на email.
  * `NEON_DB_URL` — REST-лінк бази даних Neon Serverless Postgres.
* `window.myFirebaseConfig` — конфігураційні ключі Firebase для підключення до бази Firestore проекту `lyceum8-app`.

## 🎙️ 3. РОБОТА З ГОЛОСОМ ТА ЕФЕКТИ (`voices.js`)
Скрипт [voices.js](file:///d:/Projects/ліцей_8/voices.js) керує синтезом (TTS) і розпізнаванням (STT) мовлення, а також мікро-анімаціями інтерфейсу.

### Ключовий функціонал:
1. **Синтез мовлення (`window.speakText`)**:
   * Очищення тексту (`window.cleanForSpeech`): вирізає Markdown-посилання, системні ШІ-теги на кшталт `[GENERATE_IMAGE:...]`, блоки мислення `<think>...</think>`, LaTeX формули `$$...$$` та спецсимволи.
   * Пріоритет відтворення:
     * **ElevenLabs TTS** — якісна українська озвучка (голос Bella/Antoni) через API запити.
     * **Cloud Google TTS** — безкоштовний резерв у разі вичерпання лімітів ElevenLabs.
     * **System SpeechSynthesis** — локальний голос браузера (як крайній варіант).
2. **Розпізнавання голосу (`window.toggleSpeechRecognition`)**:
   * Використовує Web Speech API (`webkitSpeechRecognition`) з локаллю `uk-UA`. Додає текст у поле вводу та автоматично надсилає повідомлення після паузи.
3. **Ефект конфеті (`window.triggerConfetti`)**:
   * Створює MutationObserver для стеження за повідомленнями у чаті. Якщо користувач надсилає слова-тригери: "дякую", "супер", "клас", "я здав", "ура", "спасибі", "вийшло", "перемога" — запускається анімація конфеті на CSS.

## 📅 4. РОЗКЛАД УРОКІВ (`schedule.js`)
Файл [schedule.js](file:///d:/Projects/ліцей_8/schedule.js) зберігає велику статичну базу даних уроків ліцею №8 та логіку відображення.

* **Структура даних**: Об'єкт `realSchedules` містить розклад для класів (від 1-А до 11-А) та викладачів. Кожен урок описується номером, часом, предметом, ПІБ вчителя та кабінетом.
* **Сітки дзвінків**:
  * Стандартна сітка (по 45 хв).
  * 1-ші класи (уроки по 35 хв).
  * 2-гі класи (уроки по 40 хв).
  * Друга зміна для 3-4 класів (уроки по 40 хв).
* **Фільтрація та рендеринг**: Функції `setSchType`, `setSchWeek`, `setSchDay` оновлюють стан фільтрів (клас/вчитель, 1 чи 2 тиждень, день ПН-ПТ) і перемальовують картки уроків у контейнері `#sch-lessons-container`.

## 📊 6. КОНСТРУКТОР ПРЕЗЕНТАЦІЙ (`presentations.js`)
Файл [presentations.js](file:///d:/Projects/ліцей_8/presentations.js) реалізує повноцінний слайд-редактор (PowerPoint Клон).

* **Структура презентації**: Зберігається в масиві слайдів `window.presSlides`, де кожен слайд містить параметри фону (`bg`) та масив об'єктів-елементів (текст, таблиці, картинки, фігури, графіки).
* **Конструктор IDE (`window.buildPresIDEUI`)**:
  * Візуальний канвас (`#pres-visual-canvas`) з підтримкою масштабування (zoom).
  * Стрічка інструментів (Ribbon) з вкладками: Головна, Вставлення, Конструктор, Переходи, Анімація, Слайд-шоу, Вигляд.
  * Інтерактивна система Drag & Drop, обертання та зміни розміру елементів мишкою за допомогою маркерів (`.pres-handle`).
  * Контекстне меню правої кнопки миші для керування шарами (Bring to Front, Send to Back), дублювання та видалення.
* **Експорт/Імпорт**:
  * Збереження проекту в локальний JSON або завантаження в хмару Firestore.
  * Генерація презентації у формат `.pptx` на клієнті через бібліотеку `PptxGenJS`.

## 🧪 7. ПЛАТФОРМА ТЕСТІВ (`tests.js`)
Скрипт [tests.js](file:///d:/Projects/ліцей_8/tests.js) відповідає за створення та проходження тестів.

### Логіка роботи:
1. **Генерація тесту ШІ (`window.generateAITest`)**:
   * Надсилає запит до Gemini API з вимогою повернути валідний JSON-тест з певної теми та кількістю питань.
   * Парсить отриманий JSON і заповнює інтерфейс конструктора.
2. **Публікація тесту (`window.publishManualTest`)**:
   * Збирає дані конструктора (питання типу: один вибір, мульти-вибір, відкрита текстова відповідь).
   * Записує об'єкт в Firestore в колекцію `public/data/tests`.
   * Генерує унікальне посилання для проходження (`?t=testId`).
3. **Проходження тесту (`window.openTestRunner`)**:
   * Тест-раннер запускається на весь екран (`requestFullscreen`).
   * **Анти-чит система**: Слухає подію `fullscreenchange`. Якщо учень виходить із повноекранного режиму (намагається відкрити іншу вкладку чи згорнути вікно), фіксується спроба списування (збільшується `testCheatCount`) і з'являється блокуюче вікно штрафу.
   * Збереження результатів: Зберігає бали, час проходження, відповіді учня та кількість спроб згорнути екран у колекцію `test_results_{testId}`.
4. **Кабінет вчителя (`window.viewResults`)**:
   * Відображає таблицю результатів учнів для обраного тесту.
   * Дозволяє переглянути детальні відповіді кожного учня.
   * Включає ручну оцінку або автоматичну перевірку відкритих питань ШІ (`window.teacherAiRecheck`).

## 🛡️ 9. БЛОКУВАЛЬНИК СПАМУ (`noreclama` / `ad_blocker.js`)
Файл [noreclama](file:///d:/Projects/ліцей_8/noreclama) (в HTML підключений як `ad_blocker.js`) є скриптом для очищення сторінки від спаму та реклами.

* **CSS Блокування**: Додає правила приховування посилань з доменами `op.wtf` та проксі-серверами.
* **Текстовий фільтр**: Використовує `TreeWalker` для проходження по DOM-дереву текстових вузлів. Знаходить та безпечно видаляє текстовий спам від API типу "Need proxies cheaper than the market?".
* **MutationObserver**: Спостерігає за динамічними змінами на сторінці (наприклад, відповідями ШІ в реальному часі) та миттєво очищує їх за допомогою `requestAnimationFrame` та інтервального резервного таймера (1.5с).
